# Road Damage Detection System

An AI-powered application that helps identify road damages using YOLO and Streamlit.

## About the Project
This project detects road damages such as cracks from uploaded road images. It aims to make road condition monitoring easier and help identify areas that require maintenance.

## Technologies Used
- Python
- YOLO
- Streamlit
- Hugging Face
- PIL (Python Imaging Library)

## How to Run

1. Clone the repository.
2. Install the required dependencies.
3. Run the application using:

streamlit run app.py

## Project Goal
To make road damage identification simpler with the help of AI and computer vision.
